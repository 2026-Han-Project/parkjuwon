# 📈 Biz-Forecaster — AI 수요 예측 (스마트 필터)

> 외부 이벤트 우선·업종 가치사슬 연계형 **소상공인 수요예측 POC**
> 2026 한이음 드림업 프로젝트

과거 거래(발주) 내역을 바탕으로 식자재 도매업체의 **거래처별 향후 5주 수요를 예측**하는 Streamlit 웹 애플리케이션입니다. 여러 시계열·머신러닝 모델을 **앙상블**로 결합해 예측하고, 거래처를 **활동성(최근성)·거래 규모(등급)** 기준으로 필터링해 원하는 대상을 쉽게 분석할 수 있습니다.

---

## ✨ 주요 기능

- **📂 CSV 자동 파싱** — 거래내역 CSV를 업로드하면 거래처·날짜·수량을 자동 추출 (소계/누계 행 자동 제외)
- **🏆 거래처 등급 자동 분류** — 총 거래량 기준 상위 백분율로 💎VIP / 🥇Gold / 🥈Silver / 🥉Bronze 4등급 부여
- **🔎 스마트 필터** — 활동성(최근 3·6·12개월)과 거래 등급을 조합해 거래처 필터링
- **🤖 앙상블 예측** — 여러 모델의 예측을 평균 내어 향후 5주 수요 산출
- **📊 시각화** — 과거 실적 + 예측 추세를 Plotly 인터랙티브 그래프로 표시
- **💾 엑셀 다운로드** — 개별 거래처 / Top N 예측 결과를 `.xlsx`로 내보내기
- **📋 Top N 일괄 예측** — 거래량 상위 10·20·30개 거래처를 한 번에 예측

## 🧠 예측 모델 (앙상블 구성)

| 모델 | 종류 | 비고 |
|------|------|------|
| 선형 추세 (Linear Trend) | 통계 | 최근 8주 기울기 외삽, 폴백 모델 |
| Holt (지수평활) | 시계열 | 추세 반영 |
| ARIMA(1,1,1) | 시계열 | |
| RandomForest | 머신러닝 | `scikit-learn` 설치 시 |
| XGBoost | 머신러닝 | `xgboost` 설치 시 |
| LSTM | 딥러닝 | `tensorflow` 설치 시 (선택) |

> 설치된 라이브러리에 따라 자동으로 사용 가능한 모델만 앙상블에 포함됩니다.
> 데이터가 부족한 거래처는 선형 추세 모델로 자동 폴백됩니다.

## 🚀 실행 방법

### 간편 실행 (Windows)
폴더 안의 **`실행하기.bat`** 을 더블 클릭하면 가상환경 생성 → 라이브러리 설치 → 앱 실행까지 자동으로 진행됩니다.

> ⚠️ **사전 준비:** 컴퓨터에 [Python](https://www.python.org/downloads/)이 설치되어 있어야 합니다.
> 설치 시 첫 화면에서 **`Add Python to PATH`** 체크박스를 반드시 체크하세요.

### 수동 실행
```bash
# 1. 가상환경 생성 및 활성화
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux

# 2. 라이브러리 설치
pip install -r requirements.txt

# 3. 앱 실행
streamlit run app.py
```
실행하면 자동으로 웹 브라우저가 열립니다. 열리지 않으면 터미널에 표시된 `localhost` 주소로 접속하세요.

## 🗃️ 입력 데이터 형식

거래내역 CSV는 각 줄에 **거래처명 + 날짜(YYYY-MM-DD) + 수량**이 포함되어야 합니다.
`거래처명`, `거래내역조회` 헤더 행과 `(소계)`, `(누계)` 행은 자동으로 걸러집니다.

## 🔧 사용법

1. 왼쪽 사이드바에서 **거래내역 CSV 업로드**
2. **[📊 상세 분석]** 탭
   - 활동성·등급 필터로 거래처 좁히기 → 특정 거래처 선택
   - 5주 앙상블 예측 결과표 + 추세 그래프 확인 → 엑셀 다운로드
3. **[🏆 Top 거래처]** 탭
   - 거래량 상위 N개 거래처를 일괄 예측 → 종합 그래프 + 엑셀 다운로드

## 🛣️ 로드맵 (기획 대비 현황)

본 저장소는 전체 기획의 **1차 PoC**로, 현재 아래 **Layer 1(시계열 앙상블)** 이 구현되어 있습니다. 나머지는 개발 예정입니다.

- [x] **Layer 1 — 시계열 앙상블 기저 수요 예측** (현재 구현됨)
- [ ] **Layer 2 — 이벤트 우선(Event-first) 예측** : 공휴일·날씨를 외생변수로 반영, 이벤트 강도가 임계치를 넘으면 이벤트 조정치가 예측을 우선 지배
- [ ] **Layer 3 — 가치사슬 연계** : 하류(예: 김밥 전문점) 소비 수요를 선행지표로 상류(도매) 발주 수요에 시차 반영
- [ ] **설명가능성(XAI)** : SHAP 기반 기여도 → 자연어 리포트 (예: "연휴 +30%, 맑은 날씨 +15% 기여")
- [ ] 이상탐지 · 모니터링 · What-if 시뮬레이션

> 📄 상세 기획·검증 내용은 별도의 개발보고서(중간보고서)를 참고하세요. (본 저장소에는 코드만 포함)
