압축을 풀고 폴더 안에 있는 실행하기.bat (또는 톱니바퀴 모양 아이콘)을 더블 클릭하세요.

검은색 창이 뜨고 글자가 막 올라가도 놀라지 마세요. 자동으로 설치하는 중입니다.

설치가 끝나면 자동으로 웹 브라우저가 열리면서 프로그램이 시작됩니다.

⚠️ 주의사항 (필수 체크!)
이 방법이 작동하려면 사용자의 컴퓨터에 **'파이썬(Python)'**이 설치되어 있어야 합니다. 

아래 링크

파이썬 다운로드: https://www.python.org/downloads/

에서 설치해 주세요.



설치 시 주의점: 설치 첫 화면에서 반드시 [V] Add Python to PATH 라는 체크박스에 체크를 하고 Install 버튼을 눌러야 합니다. (이걸 안 하면 실행이 안 됩니다.)

이 과정만 거치면, 이후에는 언제든 아이콘만 누르면 프로그램이 실행됩니다!
